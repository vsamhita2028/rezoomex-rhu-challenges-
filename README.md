# Rezoomex booth challenge proposals

A static proposal page for two technical booth activities at React Hyderabad Utsavam 2026. The examples are for discussion; the page does not implement the games.

## Preview

Open `index.html` in a web browser. No installation or build step is required.

## Publish with GitHub Pages

1. Add `index.html`, `style.css`, and this README to a GitHub repository and push them to your default branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the branch containing the files and the **/(root)** folder, then save.
4. Once GitHub Pages finishes deploying, open the URL shown in the Pages settings. The relative stylesheet path also works when the site is hosted under a repository subpath.
